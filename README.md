# Fire and Trigger

Fire and Trigger é um RPG de turnos desenvolvido em Java e jogado no terminal. Você esta é uma cela de prisão e acorda ao lado de uma fogueira
acesa, você explora masmorras, enfrenta inimigos em combates por turnos e evolui conforme avança pelos níveis.

## Funcionalidades

- Criação de personagem com escolha de classe, raça e sexo.
- Exploração de masmorras com eventos aleatórios (inimigos, baús e saída).
- Combate por turnos com inimigos de dificuldade crescente.
- Sistema de progressão: nível, experiência e evolução de atributos.
- Uso de poções de vida e mana durante o jogo.
- Sistema de salvar e carregar progresso.

## Como jogar

1. Abra o projeto em uma IDE (IntelliJ Idea, Netbeans).
2. Execute a classe `fireandtrigger.java`.
3. Na tela inicial, escolha "Novo Jogo" ou "Carregar Jogo".
4. Crie seu personagem informando nome, classe, raça e sexo.
5. Explore a masmorra.
